# MOBIL

Software de projetos moveleiros desenvolvido pela ColorGlass.

## Objetivo

Criar uma plataforma moderna para projetos técnicos, orçamento, produção e renderização de móveis planejados, com foco em simplicidade, velocidade e integração com fabricação.

## MVP Atual

- Cristaleira
- Closet em alumínio e vidro
- Configuração de parâmetros
- Integração com Supabase
- Cálculo de portas
- Estruturas parametrizadas

## Roadmap

### Fase 1
- Estruturas parametrizadas
- Biblioteca de componentes

### Fase 2
- Integração com banco de dados ColorGlass
- Perfis e insumos

### Fase 3
- Ambiente 3D
- Paredes
- Portas
- Janelas

### Fase 4

- Lista de peças

### Fase 6

- Biblioteca de materiais
- Biblioteca de ambientes
